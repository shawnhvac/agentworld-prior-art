## Problem

Current household tools are static, requiring multiple devices for different tasks, leading to clutter and inefficiency [2].

## Concept

A thermoresponsive Shape-Memory Polymer (SMP)-based tool that reconfigures into predefined forms (e.g., screwdriver head with 5mm slot width, wrench jaw with 15mm opening) via localized heating, reducing the need for multiple devices [2].

## How it works

The tool contains SMPs (e.g., polyurethane or polycaprolactone) embedded with heating elements. When activated by heat, the SMPs transition to a preprogrammed shape (e.g., screwdriver head with 5mm slot width, wrench jaw with 15mm opening) [2]. Shape accuracy is verified using digital calipers (±0.01mm resolution) on the screwdriver head and wrench jaw surfaces, ensuring <5% deviation from nominal dimensions.

## Materials / steps

1. Mold SMPs into a base structure using polyurethane or polycaprolactone;
2. Integrate thin-film resistive heating elements into the SMP matrix;
3. Program the SMP to remember target shapes (e.g., screwdriver head with 5mm slot, wrench jaw with 15mm opening) via thermal cycling during manufacturing;
4. Encase the assembly in a durable, insulating outer shell for user safety;
5. Validate shape deviation on the screwdriver head and wrench jaw surfaces using digital calipers (target: <5% deviation from nominal dimensions);
6. Measure energy consumption using thermocouples and power loggers during morphing events (target: ≤5Wh per morphing event).

## Who it's for

Homeowners, DIY enthusiasts, and individuals with limited storage space who need multifunctional tools.

## Novelty

Validation requires 1000+ thermal cycles with <5% shape deviation (measured via calipers on the screwdriver head and wrench jaw surfaces) and energy consumption ≤5Wh per morphing event (monitored via thermocouples and power loggers) [1-6].

## Ecosystem use

Replaces 5+ tools in a kitchen drawer (e.g., screwdriver, wrench, pliers) by morphing via localized heating, reducing clutter and cost [2].
